# 简册 · 安卓端

「简册」个人电子档案袋的 Flutter 客户端，与网页版共用同一个账号和同一套 REST API。

## 运行

```bash
flutter pub get
flutter run
```

登录页填服务端地址。本机联调时服务端要监听全部网卡，手机才连得上：

```bash
cd ../campus-archive
npx next dev -H 0.0.0.0 -p 3000
```

然后在 App 里填 `http://<电脑的局域网IP>:3000`。手机和电脑连同一个 WiFi，连不上大概率是 Windows 防火墙拦了 3000 端口。

## 在线 / 离线

只有一种账号模式，与网页版一致，默认离线优先：

- 在线时与服务器实时双向同步，先推送本地改动，再拉取云端全量
- 离线时所有操作照常，归档、编辑、删除、导出先写进本机镜像（SQLite + 加密文件）并进入待同步队列；网络恢复后自动上传，另带 30 秒重试
- 服务器数据是唯一权威来源，本机保存全量镜像，列表秒开，敏感证件也能离线解密查看（二次验证离线时回退到本地密码哈希）
- 敏感文件上传前先在本地用用户密钥解密，再交给服务器按网页版同一套逻辑加密存储

## 代码结构

```
lib/
├── main.dart            入口
├── theme.dart           纸色 / 墨色 / 印章红主题
├── data/
│   ├── api_client.dart  服务端接口封装（Cookie 会话 30 天）
│   ├── db.dart          本地 SQLite 镜像
│   ├── models.dart      与网页端对齐的数据模型
│   ├── repo.dart        数据仓库，在线 / 离线统一入口
│   ├── crypto.dart      AES-256-GCM 本地加解密
│   ├── e2ee.dart        端到端加密密钥派生与包裹
│   ├── exporter.dart    本地导出
│   └── format.dart      日期与文件大小格式化
├── pages/               各页面（首页、分类、证书、导出、扫描、设置等）
├── state/store.dart     应用状态
└── ui/                  通用组件、动效、底部弹层
```

## 数据模型

与网页端完全对齐：五大分类 21 个子类使用固定 key，证书七档级别、文档与导出记录字段两端一致。对齐关系见 `lib/data/models.dart`。

## 构建要求

- Flutter SDK
- 环境变量 `GRADLE_USER_HOME` 指向英文路径，中文路径会导致 Gradle 构建失败
- 发布签名材料（`key.properties`、`*.jks`）不入库，需自行配置
