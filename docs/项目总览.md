## 使用形态（V1.2 起：单一账号模式，离线优先）

App 只有一种账号模式，与网页版同一账号：

- **在线**：与服务器实时双向同步（推送本地改动 → 拉取云端全量）
- **离线**：所有操作照常可用——归档/编辑/删除/导出先写入本机镜像（SQLite + 加密文件）并进入待同步队列；恢复联网后（含自动监听网络变化 + 30 秒重试）自动上传
- 服务器数据是唯一权威来源；本机保存全量镜像，秒开且支持完全离线浏览（含敏感证件解密查看，二次验证离线回退本地密码哈希）
- 敏感文件上传时会先用本地密钥解密再交由服务器按网页版同套逻辑加密存储

## 快速启动

**网页版 / 服务器**：
```bash
cd campus-archive
npm run setup        # 初始化数据库 + 分类种子
npm run dev          # http://localhost:3000
# 手机联调改用：npx next dev -H 0.0.0.0 -p 3000（详见 campus-archive/README.md 末节）
```

**安卓 App**：
Android Studio 打开 `AndroidProject/campus_archive_app`，连接设备后点 Run ▶。
构建环境要求：Flutter SDK 位于 `D:\flutter`，环境变量 `GRADLE_USER_HOME=D:\gradle-home`（不能是中文路径！）。

## 技术要点备忘

- **同一套 API**：App 的 `lib/data/api_client.dart` 对接网页全部 15 个接口，Cookie 会话 30 天
- **数据模型一致**：五大分类 21 子类（固定 key）、证书 7 级别、文档/证书/导出记录字段两端完全对齐
- **敏感数据**：身份证件强制 AES-256-GCM 加密；查看/导出需密码二次验证（10 分钟窗口）
- **App 视觉**：纸色 #EFE6D3 + 墨色 #22283B + 朱红印章 #B0392D（详见 design/ 存档设计稿）
- 网页版测试：`node --env-file=.env .e2e/run.mjs`（28 项断言）

## 已知限制（V2 方向）

- 账号模式需服务器可达（局域网或部署公网）；离线改动会排队，恢复联网后自动同步
- OCR 自动识别、微信小程序端：未实现
